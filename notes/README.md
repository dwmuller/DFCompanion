# Development Notebook Directory

This folder is for:

- TODO/wish lists containing items for further consideration/design/planning.
- Notable snippets of conversation with AIs.
  - Observations from companion AIs are captured verbatim and have not necessarily been validated.

What this folder is not for:

- Verified bugs. Use GitHub's Issues for these.

Note that there are also ai-generated and maintained not files in the project root.
As of this writing, they are somewhat out of date and too voluminous.
